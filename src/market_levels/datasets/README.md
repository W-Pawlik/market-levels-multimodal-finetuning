# datasets

Etap 3.5: `planning.py` tworzy plan i kontroluje dane/profil/seedy;
`packaging.py` zapisuje małą diagnostykę JSONL i weryfikuje odtworzenie.
`approval.py` tworzy formalnie zatwierdzone kopie profili, `production.py`
buduje i odtwarza właściwy zbiór. `audit.py` opisuje strukturę bez wpływania
na dobór; `review.py` zapisuje oddzielne przykłady przeglądowe z poziomami.
Szczegóły: [format](../../../docs/datasets/FORMAT.md),
[PowerShell](../../../docs/datasets/INSTRUKCJA_POWERSHELL.md).
